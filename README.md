# sbo-baseball-guide

야구를 하나도 몰라도 SBO 경기를 즐길 수 있게 만든 초보자용 야구 학습 사이트 ⚾

- `index.html` — 기본편: 점수·베이스·스트라이크/볼·아웃·안타·홈런·이닝, 전광판 읽기, 퀴즈
- `guide.html` — 야구 생존 가이드: 포지션, 도루·견제, 포스아웃·태그아웃, 태그업, 헷갈리는 규칙, 중계 문장 해석, 상황 퀴즈
- `player.html` — 내가 오늘 선수라면?: 타자·투수·포수 역할 가이드

HTML / CSS / JavaScript만 사용해서 빌드 없이 `index.html`을 열면 바로 동작합니다.
콘텐츠는 `data.js`, `guide-data.js`, `player-data.js`에서 수정할 수 있습니다.
