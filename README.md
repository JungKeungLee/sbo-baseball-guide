# sbo-baseball-guide

야구를 하나도 몰라도 SBO 경기를 즐길 수 있게 만든 초보자용 야구 가이드 ⚾

처음에는 핵심만 보여주고, 자세한 내용은 펼쳐볼 때만 나오는 구조예요.

| 메뉴 | 파일 | 내용 |
| --- | --- | --- |
| 🏠 홈 | `index.html` | 메뉴 카드 5개와 진행률 |
| ⚾ 처음 보는 야구 | `basics.html` | 점수·베이스·스트라이크/볼·아웃·안타·홈런·이닝, 전광판, 한 줄 요약 (한 단계씩) |
| 🧢 선수들은 어디에 있어? | `positions.html` | 포지션 배치도, 포지션별 역할, 내야/외야 |
| 🤔 왜 저렇게 해? | `rules.html` | 도루·견제, 포스아웃·태그아웃, 태그업, 작전, 중계 용어, 기록, 헷갈리는 규칙, 중계 문장 해석 |
| 👤 내가 선수라면? | `player.html` | 타자·투수·포수 역할 가이드 |
| 🏆 야구력 테스트 | `quiz.html` | 기본·위치 맞히기·포지션·가능/불가능·실제 상황·최종 테스트 |

HTML / CSS / JavaScript만 사용해서 빌드 없이 `index.html`을 열면 바로 동작합니다.

## 콘텐츠 수정

- `data.js` — 처음 보는 야구 (단계 카드, 전광판 예시, 기본 퀴즈)
- `guide-data.js` — 포지션 · 룰 페이지의 챕터와 카드, 야구장 애니메이션, 용어 사전, 퀴즈
  - 챕터의 `track` 으로 어느 페이지에 나올지 정함 (`pos` / `rule` / `quiz`)
  - 카드: `q`(질문형 제목) · `short`(한 줄) · `key`(핵심 3가지) · `visual` · `scenarios` · `rows`/`detail`(자세히 보기)
  - `level` 1 은 펼친 채로, 2·3 은 제목만 보이게 접혀서 나옴
- `player-data.js` — 타자·투수·포수 가이드

## 코드 구조

- `nav.js` — 모든 페이지 공통 상단 메뉴
- `diamond.js` — 재사용 야구장 컴포넌트 `BaseballDiamond` (선수·주자·베이스·공 이동을 데이터로 제어)
- `guide-ui.js` — 공통 카드 하단(그림 + 상황 보기 + 자세히), 퀴즈 엔진 등
- `app.js` / `guide.js` / `player.js` / `quiz.js` / `home.js` — 페이지별 화면
- `guide.html` — 예전 주소를 새 페이지로 넘겨주는 이동용 페이지
